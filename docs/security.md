# Security and privacy

* **No training on your data.** API inputs and outputs are never used to train our models.
* **Retention.** Data is retained for 30 days for abuse monitoring by default; zero-retention is available on enterprise plans.
* **Compliance.** SOC 2 Type II and HIPAA-eligible.
* **Data residency.** Regional processing in the US, EU, and APAC.
